## Do Not Upload Without Extra Review

- Selfie-style venue image with recognizable minors in sports clothes.
- Frames with visible personal name tags.
- Frames where `Тревога` or other sensitive labels dominate the creative.
- Frames where the venue logo becomes stronger than the intensive itself, unless venue/logo permission is confirmed.

## SEO / Metadata Layer

- Public file names are Latin-only and contain useful machine-readable tokens: `moonn`, `teen-intensive`, `new-league`, `dialogue`, `flipchart`, `ai-practice`.
- Do not place internal keyword tokens as visible ad text.
- Recommended alt text for site reuse:
  - `Подростковый интенсив Татьяны Мунн в Москве, работа в малой группе`
