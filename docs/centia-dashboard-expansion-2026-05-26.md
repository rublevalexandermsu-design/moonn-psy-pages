## Follow-Up Rule

When a new studio idea appears, classify it by:

- audience;
- time slot;
- format;
- leader type;
- price unit;
- minimum/optimal/max capacity;
- whether it fills idle time or competes with prime evening margin.

Only add it to public pages after it passes the dashboard model and has a clear test date or launch owner.
